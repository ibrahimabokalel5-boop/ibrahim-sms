# منصة ومتجر الخدمات الرقمية الشاملة (E-Commerce Platform & Digital Hub)

منصة تجارية متكاملة وموقع ويب تقدمي (PWA) لشحن الألعاب، الاشتراكات الرقمية، بطاقات الهدايا، أرقام التفعيل، وخدمات السوشيال ميديا، مدعومة ببوت تيليجرام تفاعلي ولوحة إدارة كاملة.

---

## 🌟 الميزات الرئيسية

- 🎮 **شحن الألعاب الفوري بالآيدي:** ببجي موبايل (PUBG UC)، فري فاير (Free Fire)، روبلوكس (Robux)، كول أوف ديوتي (COD Mobile).
- 📱 **الاشتراكات والتطبيقات:** يوتيوب بريميوم، نتفلكس 4K، شات جي بي تي (ChatGPT Plus)، كانفا برو (Canva Pro)، سبوتيفاي.
- 💳 **البطاقات الرقمية:** جوجل بلاي، آبل آيتونز، بلايستيشن، إكس بوكس.
- 📲 **أرقام التفعيل المؤقتة:** أرقام افتراضية وتلقي كودات SMS من أكثر من 180 دولة مع Hero-SMS و SMS-Activate.
- 🛍️ **سلة مشتريات ودفع إلكتروني:** دعم سيريتل كاش، شام كاش، USDT TRC-20، والحوالات البنكية والنقدية.
- 🤖 **بوت تيليجرام تفاعلي:**
  - إشعار فوري لمدير المتجر عند إنشاء كل طلب جديد.
  - أزرار قبول وإكمال ورفض الطلبات مباشرة من التيليجرام بنقرة واحدة.
  - أوامر للزبائن لتتبع طلباتهم (`/track <order_num>`) وفتح المتجر داخل التيليجرام.
- 📲 **تطبيق هاتف تقدمي (PWA):** إمكانية تثبيت المتجر كأيقونة تطبيق كاملة على أجهزة أندرويد وآيفون وسطح المكتب.
- 👑 **لوحة تحكم إدارة المتجر (Admin Dashboard):**
  - فلاتر للطلبات (معلقة، جاري الشحن، مكتملة، ملغية).
  - إحصائيات المبيعات والأرباح الحقيقية من قاعدة بيانات SQLite.
  - أزرار نسخ المعرف ومراسلة الزبون عبر الواتساب بنقرة زر.
- 🔍 **نظام تتبع مباشر للزبائن:** تتبع حالة الطلب برقم الطلب أو رقم الهاتف مع مسار زمني مرئي.

---

## 🚀 التشغيل المحلي (Local Run)

1. تأكد من وجود Python 3 على جهازك.
2. انقر نقراً مزدوجاً على ملف: **`تشغيل الأداة.bat`**
3. أو نفّذ الأمر التالي في سطر الأوامر:
   ```bash
   python app_server.py --open
   ```
4. سيفتح المتصفح تلقائياً على الرابط: `http://localhost:8080`

## ☁️ النشر على السحابة (GitHub & Render)

الملفات مهيأة بالكامل للنشر الفوري:
- `render.yaml` - مخطط البناء التلقائي على Render (Blueprint).
- `Procfile` - أمر تشغيل سيرفر Gunicorn.
- `requirements.txt` - التبعيات المطلوبة.

راجع الدليل التفصيلي المصور في الملف: **[DEPLOYMENT_GUIDE.md](DEPLOYMENT_GUIDE.md)**

## ⚙️ التقنيات المستخدمة

- **Frontend:** HTML5, CSS3 Glassmorphism, Modern Vanilla JavaScript, Service Worker (PWA).
- **Backend:** Python Flask, SQLite3 Database Engine, RESTful APIs, Threaded Telegram Polling & Webhook.
- **Production Server:** Gunicorn WSGI Server.
